# Domain Glossary

Use this file to maintain shared terminology.

Consistent terminology significantly improves communication, AI consistency, and implementation quality.

| Term | Meaning |
|------|---------|
| User | The person writing poems in the app |
| Play | A named folder that groups related poems (e.g., "Summer 2024", "Love Poems") |
| Poem | A single piece of writing with a title and a body (free-form text) |
| Review | An AI-generated evaluation of a poem across multiple grading aspects |
| Grade | A score (e.g., 1–5) assigned by the AI to a specific aspect of a poem |
| Aspect | A dimension used in grading: rhythm, imagery, emotion, structure |
| Suggestion | An AI-generated direction for improvement — phrased as a question or prompt, never as written content |
| Poet Comparison | An AI analysis identifying which well-known poets the user's style resembles, with a brief explanation |
| AI Feature | Any on-demand capability powered by an LLM (Review or Poet Comparison) |
| Spec | An incremental implementation unit — one screen of work, one deployable slice |
